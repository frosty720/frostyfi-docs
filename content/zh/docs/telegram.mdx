# Telegram

通过 Telegram 与你的[助手](/docs/assistants)聊天：发送消息、照片和语音消息，在助手之间切换，并在手机上收到定时任务的回答。Telegram 运行在你的 FrostyFi 账户之上，因此助手的记忆、技能和工具与在应用中完全一致。

## 连接

1. 打开你的某个助手，找到 **Telegram** 面板。点击**连接 Telegram**。
2. 点击**打开 Telegram**，然后在与 FrostyFi 机器人的聊天中点按 **Start**。该链接只能使用一次，有效期 15 分钟。
3. 回到 FrostyFi，面板会显示请求连接的 Telegram 账户。确认它是你自己的，然后点击**确认**（或**拒绝**）。只确认你自己的账户：你确认的人可以以你的身份与该助手聊天。
4. 机器人会在 Telegram 中确认。你现在发给它的消息会交给这个助手。

![连接之前的助手 Telegram 面板](/screenshots/assistant-telegram.png)

![在 Telegram 中连接：点按 Start，然后在 FrostyFi 中确认](/screenshots/telegram-connect.png)

一个 Telegram 账户只能连接一个 FrostyFi 账户，并且机器人只在私聊中回答。你的 Telegram 对话也会作为聊天保存在 FrostyFi 中。

机器人会使用你的 Telegram 应用的语言回复。

## 命令

| 命令 | 作用 |
|---|---|
| `/new` | 开始新的对话 |
| `/agents` | 列出你的助手 |
| `/use 2` | 切换到该列表中的第 2 个（或输入其名称的一部分） |
| `/unlink` | 断开此聊天与 FrostyFi 的连接 |
| `/help` | 显示机器人的使用方法 |

![机器人确认连接，/agents 列出你的助手](/screenshots/telegram-agents.png)

你也可以在应用中切换：打开另一个助手，在其 Telegram 面板中点击**在 Telegram 中使用这个助手**。

## 消息、照片和语音

- **文字**：助手在 Telegram 中回答；较长的回答会拆分成多条消息。
- **一次一条**：它在回答时，新发的消息会收到「还在处理你的上一条消息…」。等回答到达后再重新发送。
- **照片**：发送照片（可附带说明文字），助手就能看到它。
- **语音消息**（Pro 版和企业版）：机器人会先回复「🎤 我听到的是：“…”」，方便你发现听错的地方，然后助手回答你说的内容。语音消息由 Gemini 3.8 Flash 识别，并使用你套餐的额度；每条最长 5 分钟。在免费版上，机器人会请你改发文字。
- 助手始终以文字回答。贴纸、文件和视频暂不支持读取。

![语音消息：机器人先显示听到的内容，然后助手回答](/screenshots/telegram-voice.png)

## 定时回答

当助手有[定时任务](/docs/assistants)时，每次的回答也会发送到你的 Telegram 聊天。回复它即可继续追问：对话会从该任务停下的地方接着进行。

## 在 Telegram 中能运行什么

出于安全考虑，有些操作只能在 FrostyFi 本身中运行：

- **可能转移资金的工作流**和 **MCP 工具**绝不会在 Telegram 中运行。即使有人进入了你的 Telegram 账户，你的钱包也不会被触及。
- **需要你批准的步骤**（测试、发布、部署、暂停、恢复和定时任务）在应用中完成；助手会指引你过去。
- **会发布内容的工作流**（X、Telegram、Discord、短信、电子邮件）可以在 Telegram 中运行。

与机器人的 Telegram 聊天没有端到端加密：你的消息和助手的回答会经过 Telegram 的服务器。

## 断开连接

在 Telegram 中发送 `/unlink`，或在助手的 Telegram 面板中点击**断开连接**。
