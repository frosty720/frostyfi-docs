# Getting Started

このガイドでは、ホスティングされたアプリ
[app.frostylabs.ai](https://app.frostylabs.ai) での最初の 5 分間を説明します。サインイン、
最初のチャットの送信、モデルの選択、そしてテンプレートからのワークフロー作成です。

## 1. サインイン

FrostyFi は **ThirdWeb Auth** を使用します。認証はウォレットベースで、セッションは
Cookie に保存される JWT（有効期間 7 日間）です。サインインには 2 つの方法があります：

- **ウォレットを接続する** — MetaMask、Coinbase Wallet、Rainbow、または任意の WalletConnect ウォレット。
  メッセージへの署名（Sign-In With Ethereum）を求められます。トランザクションもガスも不要です。
- **メール / ソーシャルログイン** — メールまたはソーシャルアカウント
  （Google など）でサインインします。ThirdWeb が裏で埋め込みウォレットを発行するため、
  シードフレーズを管理することなくオンチェーンアドレスを持てます。

いずれの方法でもウォレットアドレスが得られ、それがチャット、
ワークフロー、サブスクリプション、エージェントを横断するあなたの ID になります。

## 2. 最初のチャット

サインインすると、チャットワークスペースに到着します。メッセージを入力して送信すると、
レスポンスがリアルタイムでストリーミングされて返ってきます（FrostyFi は内部で Vercel AI SDK を使用しています）。

![FrostyFi のチャットワークスペース](/screenshots/chat-workspace.png)

チャットでできることをいくつか紹介します：

- モデルに読ませる**ファイルを添付**する。
- **アシスタントを `@mention` する** と、専用のペルソナとスキルセットを持つ推論エキスパート
  （例：アナリストやコピーライター）を呼び込めます。[コアコンセプト](/docs/concepts#assistants)を参照してください。
- **ワークフローを `@mention` する** と、あなたのワークフローの 1 つをツールとしてインラインで実行し、
  その出力を会話の中に受け取れます。

## 3. モデルを選ぶ

チャットコンポーザーの**モデルピッカー**を使って、どの AI モデルに回答させるかを選びます。ホスティングされた
どのモデルも [OpenRouter](/docs/models) 経由でルーティングされるため、プロバイダーキーをやりくりする代わりに、
単一で一貫したピッカーが得られます。

![モデルピッカー。Text / Image / Video タブと残り呼び出し回数の目安付き](/screenshots/model-picker.png)

- **Free ティア** は **無料モデル**（`:free` セット — $0 で使える強力なオープンモデル）を見られます。
- **Pro と Enterprise** は、それらに **加えて厳選された有料フラッグシップモデル** を見られます。モデルアクセスは
  バイナリ（二択）です。すべての有料ティアで *すべて* の有料モデルが使えます。「このモデルは
  Enterprise 限定」といったゲーティングはありません。

ピッカーには、モデルを切り替えると更新される **残り呼び出し回数の目安（≈）** も表示されます。
選択したモデルで月間の予算がおおよそどれくらい使えるかが分かります。この数値の
算出方法については、[モデルと使用量](/docs/models#the-calls-left-estimate)を参照してください。

## 4. テンプレートから最初のワークフローを作成する

![ワークフローテンプレートギャラリー](/screenshots/templates-gallery.png)

動作するワークフローを最短で手に入れる方法は、**テンプレート** を複製することです：

1. サイドバーから **Templates** を開く。
2. ギャラリーを閲覧または検索する（テンプレートはカテゴリ別にグループ化されています — 暗号資産/トレーディング、
   自動化など）。
3. **Use template** をクリックする。FrostyFi はテンプレートをあなた自身のワークスペースに複製します（ノード ID が
   再マッピングされるので、完全にあなたが編集できるものになります）。
4. **ビジュアルワークフロービルダー** に移動し、そこでノードを配線し直したり、
   プロンプトを変更したり、ステップを追加したりできます。

![ビジュアルワークフロービルダー](/screenshots/workflow-canvas.png)

すべてのワークフローは **Input** ノードで始まり **Output** ノードで終わります。各ノードが
何をするかを学ぶには、[ワークフローとノード](/docs/workflows)を参照してください。

## 5. 実行、スケジュール、デプロイ

- **インラインで実行：** チャットからワークフローを `@mention` して一度実行し、出力を確認します。
- **スケジュールまたはウェブフックでトリガー：** [Frosty Engine](/docs/workflows#frosty-engine) にデプロイして、
  cron スケジュールで、または外部サービスがそのウェブフックを呼び出したときに、バックグラウンドで実行します。
  （バックグラウンド実行には Pro または Enterprise の[サブスクリプション](/docs/pricing)が必要です。）
- **エージェントとして公開：** ワークフローを、他者が呼び出せる有料のオンチェーン
  [A2A エージェント](/docs/agents)に変えます。
