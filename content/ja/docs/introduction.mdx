# FrostyFi とは？

**FrostyFi** は、AI エージェントとブロックチェーンのためのビジュアルワークフロー自動化
プラットフォームです。チャットメッセージから、デプロイ可能で収益化できるオンチェーンエージェントまで、
ブラウザを離れることなく一気通貫で構築できます。

多くのツールが別々に扱ってきた 4 つの要素を組み合わせています：

1. **チャットワークスペース** — AI モデルと対話し、ファイルを添付し、ツールを呼び出す。
2. **ビジュアルワークフロービルダー** — キャンバス上にノードをドラッグ＆ドロップして、
   「RSS フィードを要約する」から「ウォレットを監視してトランザクションを送信する」まで、
   あらゆることを自動化する。
3. **デプロイ可能なエージェント** — ワークフローを、他のアプリやエージェントが呼び出せる
   ライブエージェントとして公開する。
4. **ブロックチェーンネイティブなプリミティブ** — USDC で 1 呼び出しごとに課金し（[x402](/docs/agents#x402-payments)）、
   オンチェーン ID と評価を登録し（[ERC-8004](/docs/agents#erc-8004-identity--reputation)）、
   EVM/Solana の操作をワークフローのステップとして実行する。

## 2 分で分かるプロダクト

- すべて [OpenRouter](/docs/models) 経由でルーティングされる、厳選された AI モデル群と
  **チャット**する。`@` で **アシスタント** をメンションしてドメインエキスパートを呼び込むか、
  **ワークフロー** をメンションしてツールとしてインラインで実行する。
- [`@xyflow/react`](/docs/workflows) キャンバス上で**ワークフローを構築**する。すべてのワークフローは
  **Input** ノードで始まり **Output** ノードで終わる。その間に、LLM、
  HTTP、条件、コード、EVM、Solana、Vault、ループ、連携の各ノードを配線する。
- ワークフローを **Frosty Engine** に**デプロイ**する。これは、ブラウザを開かずバックグラウンドで、
  スケジュール（cron）またはウェブフックによってワークフローを実行する実行バックエンドです。
- ワークフローを **エージェント** として公開して**収益化**する。エージェントは、
  リクエストごとに USDC マイクロペイメントを課金できる、オンチェーン ID を持つ
  [A2A](/docs/agents#a2a-protocol) 対応のエンドポイントです。

## 誰のためのものか

- AI と API を連鎖させるノーコード/ローコードな方法を求める**ビルダーと自動化担当者**。
- オンチェーンの読み書き、マルチチェーン対応（ThirdWeb 経由で 1700 以上のチェーン）、
  ウォレット操作をワークフローの一級のステップとして必要とする **Web3 開発者**。
- 標準の Agent-to-Agent（A2A）プロトコルに対応し、ERC-8004 のオンチェーン ID を備えた、
  有料で発見可能なエージェントを公開したい**エージェント開発者**。

## 現在のステータス

FrostyFi は継続的に出荷を続けています。期待値をすり合わせるためにいくつか記しておきます：

- **音声チャットはまだ利用できません。** 構築済みですが、ローンチにあたっては非表示にしています。
  OpenRouter パイプライン上へ再アーキテクトしている最中のためです（以前は単一の
  オーナーキープロバイダーに依存していました）。今後のマルチモーダルスプリントで復活します。
- **アプリはリモートの MCP サーバーのみを使用します。** セキュリティのため、FrostyFi は
  ローカルの stdio/`npx` 起動のものではなく、リモート（HTTP/SSE）の MCP サーバーに接続します。
- **$FROST トークンはまだローンチしていません。** これは収益連動型のエミッションを通じて主に **有料顧客によって獲得される** もので、
  一部はプロトコル所有流動性に資金を供給するボンドを通じて販売されます。ローンチ日は未定です — 現時点では
  プロダクトは完全に USDC で稼働しています。[トークノミクス](/docs/tokenomics)を参照してください。
