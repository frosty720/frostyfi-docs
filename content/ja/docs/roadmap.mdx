# ロードマップ

> FrostyLabs が作るすべてのもののための 1 つのトークン：$FROSTY は BaseStonk でローンチし、プレセールも発行（mint）もありません。プロダクトはトークンを必要としません。トークンはプロダクトが稼ぐものを分かち合います。

## 現在のステータス

**🚀 MVP がライブ** です（https://app.frostylabs.ai） — ビジュアルワークフロービルダー、AI チャット、マルチチェーンのウォレット操作（ThirdWeb 経由で 1700 以上のチェーン）、MCP 連携、A2A / ERC-8004 エージェント、x402 マイクロペイメント、そしてスケジュール実行とトリガー実行のワークフローのための Frosty Engine。

**オンチェーン、Base 上：** 収益スプリッター、サブスクリプションコントラクト（V2）、48 時間のガバナンスタイムロックが **デプロイされソース検証されています**。それらはすべての支払いの一部をトレジャリーへルーティングします。

## フェーズ 1 — 収益の基盤

目標：プロトコルを賄う、実際のオンチェーン収益。*（おおむね出荷済み。）*

- **どこでも USDC** — Base 上での直接の USDC サブスクリプション（Pro $5 / Enterprise $25）、古い NFT モデルを置き換える。
- **収益スプリッター** — すべての支払いが、1 つのトランザクションでアフィリエイト、オペレーティング、開発、トレジャリーにオンチェーンで分割される。*ライブ。*
- **Pay-per-deploy** — 非 LLM ワークフローをデプロイして実行するために、$5 / エージェント / 30 日。
- **アフィリエイトプログラム** — 3 レベルのリファラル帰属に加えて、収益とリンクのダッシュボード。
- **任意のワークフローをエージェントとしてデプロイ** — ビルダーから、x402 で収益化、ERC-8004 で登録。

## フェーズ 2 — 成長と FrostyG4

目標：有料サブスクライバーを増やす。

- **ユースケースを拡大** してサブスクライバーを増やす — データエージェント、ライブトレーディングと監視のテンプレート、より多くの DEX とチェーンのノード。
- **FrostyG4 を訓練・検証する** — FrostyFi 独自のファインチューンモデル（Gemma ベース）で、小さく始めて上へ卒業していく。最高のストックモデルに勝つまでは、ストックモデルにルーティングします — 早すぎるインフラは組みません。

## フェーズ 3 — $FROSTY

目標：すべてのプロダクトに結びついた 1 つのトークンを、固定された公開の条件で。

- **BaseStonk でローンチ** — 供給量 1B で固定、USDC とペア、誰も引き出せないローンチ流動性。1% の買い税 / 3% の売り税を、ホルダー（USDC で）、自動流動性、トレジャリー、開示済みのチーム取り分で均等に分配。ローンチ時に永久に固定されます。[$FROSTY](/docs/tokenomics) を参照。
- **トレジャリーによる買い戻し** — トレジャリーが稼いだものの一部で FROSTY を買い、バーンする。
- **リサーチ割引** — FROSTY ホルダーは FrostyFunds のリサーチを安く利用できる。
- **ファンドのプロトコル手数料を FROSTY で** — ファンドマネージャーはプロトコル手数料を FROSTY で半額で支払い、その FROSTY はバーンされる。

## コミットメント

> **プレセールなし、VC なし、発行（mint）なし。** 税のうちチームの取り分は [$FROSTY](/docs/tokenomics) ページで開示されており、すべての税率はプールのコントラクトで固定されています。
