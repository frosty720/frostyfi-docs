# FrostyFi

**AI エージェント + ブロックチェーンのためのビジュアルワークフロー自動化**

FrostyFi は、ブロックチェーン自動化を備えた AI 駆動ワークフローを構築するための Web3 ネイティブなプラットフォームです。

![FrostyFi のチャットワークスペース](/screenshots/chat-workspace.png)

## 機能

- **AI チャット** - OpenRouter 経由でルーティングされる厳選されたモデル
- **ビジュアルワークフロー** - ドラッグ＆ドロップのビルダー：LLM、HTTP、条件、コード、EVM、Solana、Vault、ループ、および連携ノード
- **デプロイ可能なエージェント** - ワークフローをオンチェーン ID を持つ A2A エージェントとして公開
- **ブロックチェーンネイティブ** - Base 上での x402 USDC マイクロペイメント + ERC-8004 の ID・評価
- **MCP 連携** - リモートの Model Context Protocol ツールサーバーに接続
- **Frosty Engine** - スケジュール（cron）およびウェブフックでトリガーされるバックグラウンドワークフロー
- **USDC サブスクリプション** - Base 上の Free、Pro（$25）、Enterprise（$99）ティア
