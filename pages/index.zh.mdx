# FrostyFi

**面向 AI 智能体与区块链的可视化工作流自动化平台**

FrostyFi 是一个 Web3 原生平台，用于构建由 AI 驱动、结合区块链自动化的工作流。

![FrostyFi 聊天工作区](/screenshots/chat-workspace.png)

## 功能特性

- **AI 聊天** —— 经由 OpenRouter 路由的精选模型
- **可视化工作流** —— 拖放式构建器：LLM、HTTP、条件、代码、EVM、Solana、Vault、循环及各类集成节点
- **可部署智能体** —— 将工作流发布为具备链上身份的 A2A 智能体
- **区块链原生** —— 基于 Base 的 x402 USDC 微支付 + ERC-8004 身份与信誉
- **MCP 集成** —— 连接远程 Model Context Protocol 工具服务器
- **Frosty Engine** —— 定时（cron）与 webhook 触发的后台工作流
- **USDC 订阅** —— Base 上的免费版、Pro 版（$25）与企业版（$99）套餐
