# FrostyFi

**AI 에이전트와 블록체인을 위한 비주얼 워크플로우 자동화**

FrostyFi는 블록체인 자동화와 함께 AI 기반 워크플로우를 구축하는 Web3 네이티브 플랫폼입니다.

![FrostyFi 채팅 워크스페이스](/screenshots/chat-workspace.png)

## 기능

- **AI 채팅** - OpenRouter를 통해 라우팅되는 엄선된 모델
- **비주얼 워크플로우** - 드래그 앤 드롭 빌더: LLM, HTTP, 조건, 코드, EVM, Solana, Vault, 루프, 그리고 통합 노드
- **배포 가능한 에이전트** - 워크플로우를 온체인 아이덴티티를 갖춘 A2A 에이전트로 게시
- **블록체인 네이티브** - Base 위의 x402 USDC 마이크로페이먼트 + ERC-8004 아이덴티티 및 평판
- **MCP 통합** - 원격 Model Context Protocol 도구 서버 연결
- **Frosty Engine** - 스케줄(cron) 및 웹훅으로 트리거되는 백그라운드 워크플로우
- **USDC 구독** - Base 위의 Free, Pro($25), Enterprise($99) 등급
