# 智能体、A2A 与支付

在 FrostyFi 中，**智能体（Agent）**是你部署为实时可调用端点、并拥有链上身份的[工作流](/docs/workflows)。本页介绍如何部署智能体，以及使智能体可被发现、可被付费调用、可信赖的三大区块链原生系统：**A2A 协议**、**x402 支付**与 **ERC-8004 身份**。

> 来自[核心概念](/docs/concepts)的提醒：只有**由工作流支撑的智能体**才会成为 A2A / x402 / ERC-8004 端点。推理型**助手**只存在于聊天中——要部署类助手的行为，请先将其构建进一个工作流。

## 将工作流部署为智能体

1. 构建并**发布**你的工作流。它必须带有引擎可调用的触发器——实践中通常是 **webhook** 触发器（这样智能体端点才能调用它）。
2. 在工作流构建器的头部，点击**部署为智能体**（面向已发布工作流的付费套餐提供）。
3. FrostyFi 会为该工作流查找或创建智能体记录，并打开 **A2A 部署弹窗**，你在其中设置 **x402 价格**与**网络**。
4. 确认。你的智能体现已上线，拥有 A2A 端点和一张智能体卡片。

默认的每次调用价格为 **0.01 USDC**；你可以修改它（或设为免费）。

## A2A 协议

**A2A（Agent-to-Agent）**是智能体之间相互通信所使用的标准 JSON-RPC 协议。部署后，你的智能体会暴露：

- 位于 `/.well-known/agent-card.json` 的**智能体卡片**——一份机器可读的智能体描述（其名称、技能、端点及支付要求），使其他智能体能够发现并理解它。
- 一个接受标准方法的 **JSON-RPC 2.0 端点**：
  - `message/send` —— 向智能体发送请求并取回其输出。
  - `tasks/get` —— 轮询某个任务的状态/结果。
  - `tasks/cancel` —— 取消某个任务。

当调用方访问 `message/send` 时，FrostyFi 通过 [Frosty Engine](/docs/workflows#frosty-engine) 执行底层工作流，并将工作流的**输出**返回给调用方。

## x402 支付

**x402** 是一种按请求计费的微支付协议：智能体针对每次调用收取少量 **Base 上的 USDC**。它使用标准的 HTTP `402 Payment Required` 流程：

1. 调用方请求智能体。智能体以 **402** 响应，附带支付要求（金额、网络、代币、收款方）。
2. 调用方签署一份 **EIP-3009** USDC 授权，并带上 `X-PAYMENT` 头重试。
3. 智能体通过 facilitator **验证**支付。
4. 智能体**执行工作流**（先执行再结算——因此失败的运行不会被收费）。
5. 智能体在链上**结算**支付（真实的 USDC 转移），随后返回结果，并附带 `X-PAYMENT-RESPONSE` 收据头。

这使得每一次智能体调用都成为一笔微小的、无需信任的交易——无需 API 密钥、无需开票、无需账户。FrostyFi 默认使用 ThirdWeb x402 facilitator，完整的 402 → 支付 → 验证 → 执行 → 结算 循环已在 Base 上完成端到端验证。

> 金额以原子级 USDC 单位表示（USDC 有 6 位小数），因此 `"10000"` = 0.01 USDC。

每个已部署的智能体都会显示一段可直接粘贴的**「如何调用」**代码片段——其端点、`agent-card.json` URL、每次调用价格，以及一个一行即可完成付款的 `x402-fetch` 示例：

## ERC-8004 身份与信誉

**ERC-8004** 为智能体赋予**链上身份与信誉**，让调用方能够信任自己付费的对象。它构建于三个链上注册表之上：

- **身份注册表（Identity Registry）** —— 在链上注册智能体，并指向其注册文件（描述其 A2A 服务与 schema）。注册由所有者驱动，并与智能体创建者的钱包绑定，因此智能体身份无法被伪造。
- **信誉注册表（Reputation Registry）** —— 保存关于智能体的反馈。反馈是无需许可的：任何与智能体交互过的人都可以留下链上反馈，且智能体的信誉摘要可在链上读取。
- **验证注册表（Validation Registry）** —— 用于关于智能体执行的证明（前瞻性功能；对应可验证执行的使用场景）。

FrostyFi 在 Base 主网（以及用于测试的 Base Sepolia）上支持 ERC-8004；所有主网智能体共享同一个身份注册表和同一个信誉注册表地址。已注册的智能体会在 UI 中获得 **Basescan** 与 **8004scan** 浏览器链接以及一张信誉卡片。

## 市场

已部署的智能体可以在**智能体市场（Agent Marketplace）**中挂牌，供他人发现并调用。市场会展示智能体的卡片、价格，以及（对已注册 ERC-8004 的智能体而言）其链上信誉——从而把你的工作流变成一款他人与其他智能体都能找到并付费使用的产品。

![A2A 市场——一个已部署的智能体，附带其 x402 价格与 ERC-8004 验证](/screenshots/a2a-marketplace.png)

## 创作者仪表盘

**创作者仪表盘（Creator Dashboard）**追踪你部署的每一个智能体：USDC 总收益、执行次数、成功率、延迟、独立买家数量，以及你表现最佳的智能体——另外还有按天的收益图表、链上支付历史，以及你的**联盟（推荐）**收益。

![创作者仪表盘——一目了然的智能体收益与表现](/screenshots/dash-1.png)

## 组合起来

```
Caller ──message/send──►  Agent (A2A endpoint)
                              │  402 + x402 requirements
        ◄─────402───────------┘
Caller ──sign EIP-3009 USDC, retry with X-PAYMENT──►
                              │  verify → execute workflow (Frosty Engine) → settle USDC
        ◄── result + X-PAYMENT-RESPONSE receipt ───┘

  Identity & trust:  ERC-8004 (on-chain identity + permissionless reputation)
  Discovery:         Agent card (/.well-known/agent-card.json) + Marketplace
```
