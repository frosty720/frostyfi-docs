# 시작하기

이 가이드는 [app.frostylabs.ai](https://app.frostylabs.ai)의 호스팅된 앱에서 처음
5분 동안 로그인하고, 첫 채팅을 보내고, 모델을 선택하고, 템플릿에서 워크플로우를
만드는 과정을 안내합니다.

## 1. 로그인

FrostyFi는 **ThirdWeb Auth**를 사용합니다 — 인증은 지갑 기반이며, 세션은
쿠키에 저장된 JWT입니다(7일간 유효). 로그인하는 방법은 두 가지입니다:

- **지갑 연결** — MetaMask, Coinbase Wallet, Rainbow, 또는 모든 WalletConnect 지갑.
  메시지에 서명하도록 요청받습니다(Sign-In With Ethereum). 트랜잭션도, 가스도 없습니다.
- **이메일 / 소셜 로그인** — 이메일이나 소셜 계정(Google 등)으로 로그인합니다.
  ThirdWeb가 백그라운드에서 임베디드 지갑을 프로비저닝해주므로, 시드 문구를 관리하지
  않고도 온체인 주소를 갖게 됩니다.

어느 방식이든 지갑 주소를 갖게 되며, 이는 채팅, 워크플로우, 구독, 에이전트 전반에서
여러분의 아이덴티티가 됩니다.

## 2. 첫 채팅

로그인하면 채팅 워크스페이스에 도착합니다. 메시지를 입력하고 전송하세요 — 응답이
실시간으로 스트리밍됩니다(FrostyFi는 내부적으로 Vercel AI SDK를 사용합니다).

![FrostyFi 채팅 워크스페이스](/screenshots/chat-workspace.png)

채팅에서 할 수 있는 몇 가지:

- 모델이 읽을 수 있도록 **파일 첨부**하기.
- **`@멘션`으로 어시스턴트 호출** — 맞춤형 페르소나와 스킬 세트를 갖춘 추론 전문가를
  불러옵니다(예: 애널리스트 또는 카피라이터). [핵심 개념](/docs/concepts#assistants)을 참조하세요.
- **`@멘션`으로 워크플로우 실행** — 여러분의 워크플로우 중 하나를 도구처럼 인라인으로
  실행하고 그 결과를 대화 안에서 받습니다.

## 3. 모델 선택

채팅 작성기의 **모델 선택기**를 사용하여 어떤 AI 모델이 응답할지 선택하세요. 모든
호스팅 모델은 [OpenRouter](/docs/models)를 통해 라우팅되므로, 제공자 키를 이리저리
관리하는 대신 단일하고 일관된 선택기를 사용할 수 있습니다.

![Text / Image / Video 탭과 남은 호출 추정치가 있는 모델 선택기](/screenshots/model-picker.png)

- **Free 등급**은 **무료 모델**(`:free` 세트 — $0의 강력한 오픈 모델)을 볼 수 있습니다.
- **Pro와 Enterprise**는 그에 더해 **엄선된 유료 플래그십 모델**을 볼 수 있습니다. 모델 접근은
  이분법적입니다: 모든 유료 등급이 *모든* 유료 모델을 사용하며 — "이 모델은
  Enterprise 전용"과 같은 게이팅은 없습니다.

선택기는 또한 모델을 전환할 때 업데이트되는 **≈ 남은 호출** 추정치를 표시하므로,
선택한 모델에서 월간 예산으로 대략 얼마나 사용할 수 있는지 확인할 수 있습니다. 이
숫자가 어떻게 계산되는지는 [모델 & 사용량](/docs/models#the-calls-left-estimate)을 참조하세요.

## 4. 템플릿에서 첫 워크플로우 만들기

![워크플로우 템플릿 갤러리](/screenshots/templates-gallery.png)

작동하는 워크플로우를 얻는 가장 빠른 방법은 **템플릿**을 복제하는 것입니다:

1. 사이드바에서 **Templates**를 엽니다.
2. 갤러리를 둘러보거나 검색하세요(템플릿은 카테고리별로 분류되어 있습니다 — 크립토/트레이딩,
   자동화 등).
3. **Use template**을 클릭합니다. FrostyFi가 템플릿을 여러분의 워크스페이스로 복제합니다(노드 ID가
   재매핑되어 완전히 여러분이 편집할 수 있는 것이 됩니다).
4. **비주얼 워크플로우 빌더**로 이동하며, 여기서 노드를 다시 연결하고, 프롬프트를 변경하고,
   단계를 추가할 수 있습니다.

![비주얼 워크플로우 빌더](/screenshots/workflow-canvas.png)

모든 워크플로우는 **Input** 노드에서 시작하고 **Output** 노드에서 끝납니다. 각 노드가
무엇을 하는지 알아보려면 [워크플로우 & 노드](/docs/workflows)를 참조하세요.

## 5. 실행, 스케줄링 또는 배포하기

- **인라인 실행:** 채팅에서 워크플로우를 `@멘션`하여 한 번 실행하고 결과를 확인합니다.
- **스케줄 또는 웹훅 트리거:** [Frosty Engine](/docs/workflows#frosty-engine)에 배포하여
  cron 스케줄에 따라 또는 외부 서비스가 웹훅을 호출할 때 백그라운드에서 실행되도록 합니다.
  (백그라운드 실행에는 Pro 또는 Enterprise [구독](/docs/pricing)이 필요합니다.)
- **에이전트로 게시:** 워크플로우를 다른 사람들이 호출할 수 있는 유료 온체인
  [A2A 에이전트](/docs/agents)로 만듭니다.
