# 常见问题

## 通用

**问：FrostyFi 是什么？**
答：一个 Web3 原生平台，用于构建由 AI 驱动、结合区块链自动化的工作流。

**问：使用它需要加密货币吗？**
答：是的，订阅需要 Base 链上的 USDC。提供免费版供测试。

**问：它托管在哪里？**
答：app.frostylabs.ai（前端），Oracle Cloud VPS（后端）

## 技术

**问：支持哪些模型？**
答：所有主流提供商（OpenAI、Anthropic、Google、xAI、Groq 等）都可通过单一网关使用——每个聊天模型都经由 OpenRouter 路由。参见[模型与用量](/docs/models)。

**问：我可以使用自己的 API 密钥吗？**
答：不可以——LLM 访问由 FrostyFi 通过 OpenRouter 统一管理，并为每个用户设置月度预算（类似 Cursor）。你无需自带或管理提供商密钥。

**问：我的数据安全吗？**
答：安全——按用户隔离，且区块链签名通过 ThirdWeb Vault 进行，因此私钥永远不会接触你的工作流配置。

**问：我可以自托管吗？**
答：暂时不行——FrostyFi 目前仅提供 SaaS。自托管选项（Docker/Coolify）已列入[路线图](/docs/roadmap)。

## 账户

**问：我怎么找回账户？我忘记密码了。**
答：这里没有密码。FrostyFi 账户基于钱包——你的钱包**就是**你的账户。如果你的会话过期或被登出，只需重新连接同一个钱包即可回到原状，一切数据完好无损。

**问：如果我丢失了钱包访问权限怎么办？**
答：你钱包的私钥 / 助记词是唯一的恢复方式——请将其备份在安全的地方。若密钥丢失，我们或任何人都无法为你恢复账户。如果你是用邮箱或社交账号登录（ThirdWeb 内置钱包），则恢复将改为通过 ThirdWeb 绑定该邮箱/社交账号的流程进行。

## 计费

**问：订阅是如何运作的？**
答：订阅通过 `FrostySubscription` 智能合约以 Base 上的 USDC 支付——你的套餐直接根据你的钱包从链上读取。无需信用卡，无需 NFT。参见[订阅与定价](/docs/pricing)。

**问：我可以取消吗？**
答：可以——只需不续订即可。订阅到期时，你的套餐会在链上自动失效。
