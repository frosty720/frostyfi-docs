# 기능

## AI 채팅

- **멀티 모델 지원**: 단일 OpenRouter 게이트웨이를 통한 모든 주요 제공자(OpenAI, Anthropic, Google, xAI, Groq 등) — [모델 & 사용량](/docs/models)을 참조하세요
- **실시간 스트리밍**: Vercel AI SDK를 통한 라이브 응답 스트리밍
- **도구 멘션**: `@toolname`을 입력하여 특정 도구를 호출
- **도구 프리셋**: 다양한 작업을 위한 사전 구성된 도구 세트
- **도구 선택 모드**: Auto, Manual, 또는 None
- **임시 채팅**: 빠른 질문을 위한 팝업 채팅

## 비주얼 워크플로우

노드 유형 중 일부(전체 30개 이상의 라이브러리는 [워크플로우 & 노드](/docs/workflows) 참조):

| 노드 | 설명 |
|------|-------------|
| **Input** | 워크플로우 진입점 |
| **LLM** | AI 모델 상호작용 |
| **Tool** | MCP 도구 실행 |
| **HTTP** | REST API 요청 |
| **Condition** | If/else 분기 |
| **Template** | 변수 치환이 있는 텍스트 |
| **EVM** | 온체인 읽기, 전송, 컨트랙트 호출 |
| **Vault** | 지갑 키 커스터디 + 서명 |
| **Output** | 워크플로우 결과 |

기능:
- 드래그 앤 드롭 빌더
- 버전 관리
- 도구로 게시
- Frosty Engine을 통한 백그라운드 실행

## Vault

ThirdWeb Vault를 통한 안전한 키 커스터디와 서명 — 프라이빗 키는 결코 Vault를 떠나지 않습니다:

- **getWallet / createEoa / listEoas** - 서버 지갑 관리
- **signMessage** - 임의 메시지 서명
- **signTypedData** - EIP-712 타입 데이터 서명
- **signTransaction** - 트랜잭션 서명
- **signAuthorization** - EIP-3009 / 인가 서명
- Solana 대응 기능(계정 생성/목록 조회, 트랜잭션/메시지 서명)

잔액 읽기, 네이티브/토큰 전송, 컨트랙트 호출은 **EVM**과 **Solana** 노드의 역할입니다(Vault를 통해 서명). [Vault](/docs/vaults)를 참조하세요.

## MCP 통합

원격 MCP 서버 연결(호스팅된 앱은 보안을 위해 **원격 전용**입니다):

- **SSE** - Server-Sent Events
- **StreamableHTTP** - HTTP 기반 도구

마켓플레이스는 검증된 원격 서버(예: CoinGecko, Alpha Vantage, Stripe, Etherscan, Blockscout)를 제공합니다. [MCP](/docs/mcp)를 참조하세요.

## Frosty Engine

백그라운드 워크플로우 실행:

- **스케줄** - Cron 기반 자동화
- **웹훅** - HTTP로 트리거되는 워크플로우
- **등급 한도** - Pro/Enterprise 전용
- **Vault 통합** - 백그라운드에서의 블록체인 작업

## 인증

- 지갑 로그인(MetaMask, Coinbase, Rainbow, 모든 WalletConnect 지갑)
- ThirdWeb 인앱 지갑을 통한 소셜 / 이메일 로그인(Google, Discord, Telegram, X, GitHub, Coinbase, 이메일, 패스키)
- 7일 JWT 세션
