# Telegram

Telegram에서 [어시스턴트](/docs/assistants)와 채팅하세요. 메시지, 사진, 음성 메시지를
보내고, 어시스턴트를 전환하고, 예약 작업의 답변을 휴대폰으로 받을 수 있습니다. Telegram은
FrostyFi 계정으로 실행되므로, 어시스턴트의 메모리, 스킬, 도구가 앱에서와 똑같이 작동합니다.

## 연결

1. 어시스턴트 중 하나를 열고 **Telegram** 패널을 찾으세요. **Telegram 연결**을 클릭합니다.
2. **Telegram 열기**를 클릭한 뒤, FrostyFi 봇과의 채팅에서 **Start**를 누르세요. 링크는
   15분 동안 한 번만 사용할 수 있습니다.
3. FrostyFi로 돌아오면 패널에 연결을 요청하는 Telegram 계정이 표시됩니다. 본인 계정인지
   확인한 뒤 **확인**(또는 **거절**)을 클릭하세요. 반드시 본인 계정만 확인하세요. 확인한
   사람은 여러분인 것처럼 어시스턴트와 채팅할 수 있습니다.
4. 봇이 Telegram에서 연결을 알려 줍니다. 이제 봇에 보내는 메시지는 그 어시스턴트로
   전달됩니다.

![연결 전 어시스턴트의 Telegram 패널](/screenshots/assistant-telegram.png)

![Telegram에서 연결: Start를 누른 뒤 FrostyFi에서 확인](/screenshots/telegram-connect.png)

하나의 Telegram 계정은 하나의 FrostyFi 계정에만 연결되며, 봇은 비공개 채팅에서만
응답합니다. Telegram 대화는 FrostyFi에도 채팅으로 저장됩니다.

봇은 Telegram 앱의 언어로 메시지를 보냅니다.

## 명령어

| 명령어 | 기능 |
|---|---|
| `/new` | 새 대화 시작 |
| `/agents` | 어시스턴트 목록 보기 |
| `/use 2` | 목록의 2번으로 전환(또는 이름의 일부를 입력) |
| `/unlink` | 이 채팅과 FrostyFi의 연결 해제 |
| `/help` | 봇 사용법 보기 |

![봇이 연결을 확인하고 /agents가 어시스턴트 목록을 보여줍니다](/screenshots/telegram-agents.png)

앱에서 전환할 수도 있습니다. 다른 어시스턴트를 열고 해당 Telegram 패널에서
**Telegram에서 이 어시스턴트 사용**을 클릭하세요.

## 메시지, 사진, 음성

- **텍스트**: 어시스턴트가 Telegram에서 답하며, 긴 답변은 여러 메시지로 나뉩니다.
- **한 번에 하나씩**: 답하는 동안 새 메시지를 보내면 "이전 메시지를 아직 처리 중입니다…"가
  표시됩니다. 답변이 도착하면 다시 보내세요.
- **사진**: 사진을 보내면(원하면 설명 문구와 함께) 어시스턴트가 그 사진을 봅니다.
- **음성 메시지**(Pro 및 Enterprise): 봇이 먼저 "🎤 들은 내용: …"으로 답해 잘못 들은
  부분을 알아볼 수 있게 한 다음, 어시스턴트가 여러분의 말에 답합니다. 음성 메시지는
  Gemini 3.8 Flash가 듣고 요금제의 크레딧을 사용하며, 각각 최대 5분입니다. Free 요금제에서는
  봇이 텍스트로 보내 달라고 요청합니다.
- 어시스턴트는 항상 텍스트로 답합니다. 스티커, 파일, 동영상은 아직 읽지 않습니다.

![음성 메시지: 봇이 들은 내용을 보여준 뒤 어시스턴트가 답합니다](/screenshots/telegram-voice.png)

## 예약된 답변

어시스턴트에 [예약 작업](/docs/assistants)이 있으면, 각 답변이 Telegram 채팅으로도
전송됩니다. 그 메시지에 답장해 이어서 대화하세요. 작업이 끝난 지점에서 대화가 계속됩니다.

## Telegram에서 실행되는 것

안전을 위해 일부는 FrostyFi 안에서만 실행됩니다:

- **자금을 이동할 수 있는 워크플로우**와 **MCP 도구**는 Telegram에서 절대 실행되지
  않습니다. 누군가 여러분의 Telegram 계정에 접근하더라도 지갑에는 손댈 수 없습니다.
- **승인이 필요한 단계**(테스트, 게시, 배포, 일시 중지, 재개, 예약)는 앱에서 진행합니다.
  어시스턴트가 그쪽으로 안내합니다.
- **게시하는 워크플로우**(X, Telegram, Discord, SMS, 이메일)는 Telegram에서 실행됩니다.

봇과의 Telegram 채팅은 종단간 암호화되지 않습니다. 여러분의 메시지와 어시스턴트의 답변은
Telegram 서버를 거칩니다.

## 연결 해제

Telegram에서 `/unlink`를 보내거나, 어시스턴트의 Telegram 패널에서 **연결 해제**를
클릭하세요.
