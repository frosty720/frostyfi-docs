# Frosty Engine

자동화된 백그라운드 워크플로우 실행.

## 개요

Frosty Engine은 스케줄이나 웹훅을 통해 워크플로우를 실행합니다. Pro와 Enterprise 사용자가 이용할 수 있습니다.

배포된 각 워크플로우에는 그 백그라운드 실행을 보여주는 **Runs** 패널이 있습니다 — 트리거
유형(웹훅 / 스케줄), 상태, 지연 시간 — 그래서 여러분의 자동화가 어떻게 수행되고
있는지 한눈에 볼 수 있습니다.

![Runs 패널 — 상태와 지연 시간이 있는 백그라운드 실행](/screenshots/runs-panel.png)

## 기능

- **스케줄 워크플로우**: Cron 기반 자동화
- **웹훅 트리거**: 워크플로우를 트리거하는 HTTP 엔드포인트
- **등급 검증**: 매 실행마다 구독 확인
- **Vault 통합**: 백그라운드에서의 블록체인 작업
- **실행 내역**: 완전한 감사 추적

| 중지됨 | ❌ | ❌ |

## API 엔드포인트

### 배포
- `POST /api/deploy` - 워크플로우 배포
- `POST /api/deployments/:id/pause` - 일시 중지
- `POST /api/deployments/:id/resume` - 재개
- `DELETE /api/deployments/:id` - 제거

### 실행
- `POST /api/execute` - 수동 실행
- `GET /api/executions/:id` - 상태 조회

### 웹훅
- `POST /webhooks/:id` - 웹훅을 통해 배포된 워크플로우 트리거

> Cron 스케줄과 웹훅은 워크플로우의 **배포**의 일부로 구성됩니다(스케줄러와 웹훅
> 리시버가 데이터베이스에서 이를 읽습니다) — 별도의 스케줄 관리 엔드포인트는 없습니다.
