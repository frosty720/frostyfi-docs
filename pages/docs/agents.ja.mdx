# エージェント、A2A と決済

FrostyFi における **エージェント** とは、ライブで呼び出し可能な、オンチェーン ID を持つエンドポイントとして
デプロイした[ワークフロー](/docs/workflows)のことです。このページでは、エージェントのデプロイ方法と、
エージェントを発見可能・支払い可能・信頼可能にする 3 つのブロックチェーンネイティブなシステム、すなわち
**A2A プロトコル**、**x402 決済**、**ERC-8004 ID** を扱います。

> [コアコンセプト](/docs/concepts)からのリマインダー：**ワークフローに裏打ちされたエージェント** だけが
> A2A / x402 / ERC-8004 のエンドポイントになります。[アシスタント](/docs/assistants)を販売するには、
> それを実行するエージェントワークフローを作成し（下記を参照）、それをデプロイします。

## ワークフローをエージェントとしてデプロイする

1. ワークフローを構築して **公開** します。エンジンが呼び出せるトリガーが必要です — 
   実際には **webhook** トリガー（エージェントエンドポイントがそれを起動できるように）。
2. ワークフロービルダーのヘッダーで **Deploy as agent** をクリックします（公開済みワークフローに対して
   有料ティアで利用可能）。
3. FrostyFi はそのワークフローのエージェントレコードを検索または作成し、**A2A デプロイ
   モーダル** を開きます。そこで **x402 価格** と **ネットワーク** を設定します。
4. 確認します。エージェントが A2A エンドポイントとエージェントカードとともにライブになりました。

デフォルトの 1 呼び出しあたりの価格は **0.01 USDC** です。変更できます（最低価格は
**0.001 USDC** です）。

### アシスタントをデプロイする

アシスタントのエディタには **有料エージェントとしてデプロイ** パネルがあります。**エージェントワークフローを作成** を
クリックすると、アシスタントの指示、スキル、ツールを使ってアシスタントをライブで実行するワークフローが作られます。
そのワークフローを上記の手順でデプロイします。販売するアシスタントにシークレットを入れないでください。支払いをした
呼び出し元は、モデルに指示とスキルを明かすよう求めることができます。[アシスタント](/docs/assistants)を参照してください。

## 有料呼び出しでできること

有料呼び出しは、他の誰かのためにあなたのワークフローを実行するため、一部のステップには制限があります。

- **あなたの資金は動かません。** 資金を移動するステップや、あなたのウォレットで署名するステップは、
  支払いをした呼び出し元からの呼び出しでは拒否されます。呼び出しごとに API の料金を支払うステップ（x402 ノード、
  BlockRun、ウォレット支払いのモデル）は引き続き実行されます。URL と支出上限はワークフロー内で設定され、
  呼び出し元は変更できません。
- **MCP ツール**：1 つずつ個別に接続されたツールのみ利用できます。MCP サーバー全体を接続した場合は
  利用できません。
- **投稿ステップは実行されます**（X、Telegram、Discord、SMS、メール）。ワークフローに投稿ステップがある場合、
  デプロイフォームが警告を表示します。
- **開始された時点で課金**：呼び出し元は、実行が開始された時点で、結果にかかわらず支払います。
  開始できなかった呼び出しには課金されません。
- **有料エンドポイント経由のみ**：有料エージェントのワークフローは、通常のウェブフックからは起動できず、
  そのウェブフックシークレットはあなたにだけ表示されます。

## A2A プロトコル

**A2A（Agent-to-Agent）** は、エージェント同士が対話するために使う標準の JSON-RPC プロトコルです。
デプロイされると、あなたのエージェントは次を公開します：

- `/.well-known/agent-card.json` にある **エージェントカード** — エージェントの機械可読な記述
  （名前、スキル、エンドポイント、決済要件）で、他のエージェントがそれを
  発見し理解できるようにします。
- 標準メソッドを受け付ける **JSON-RPC 2.0 エンドポイント**：
  - `message/send` — エージェントにリクエストを送り、その出力を受け取る。
  - `tasks/get` — タスクのステータス/結果をポーリングする。
  - `tasks/cancel` — タスクをキャンセルする。

呼び出し元が `message/send` を叩くと、FrostyFi は
[Frosty Engine](/docs/workflows#frosty-engine) を介して裏側のワークフローを実行し、ワークフローの **出力** を
呼び出し元に返します。

## x402 決済

**x402** はリクエストごとのマイクロペイメントプロトコルです：エージェントは呼び出しごとに
少額の **Base 上の USDC** を課金します。標準の HTTP `402 Payment Required` フローを使います：

1. 呼び出し元がエージェントにリクエストします。エージェントは決済要件
   （金額、ネットワーク、トークン、受取人）とともに **402** を返します。
2. 呼び出し元は **EIP-3009** の USDC 認可に署名し、`X-PAYMENT`
   ヘッダーを付けて再試行します。
3. エージェントはファシリテーターで決済を **検証** します。
4. エージェントは **ワークフローを実行** します（実行してから決済 — 失敗した実行は
   課金されません）。
5. エージェントは決済をオンチェーンで **確定** し（実際の USDC が移動）、`X-PAYMENT-RESPONSE`
   レシートヘッダーとともに結果を返します。

これにより、すべてのエージェント呼び出しが小さくトラストレスなトランザクションになります — API キーも、請求書も、
アカウントも不要です。FrostyFi はデフォルトで ThirdWeb の x402 ファシリテーターを使用し、
402 → 支払い → 検証 → 実行 → 確定 の完全なループが Base 上でエンドツーエンドに実証されています。

> 金額はアトミックな USDC 単位です（USDC は 6 桁の小数を持つ）。したがって `"10000"` = 0.01 USDC。

デプロイされたすべてのエージェントは、貼り付けてすぐ使える **「How to call」** スニペットを表示します — エンドポイント、
`agent-card.json` の URL、1 呼び出しあたりの価格、そして 1 行で支払える `x402-fetch` の例です：

## ERC-8004 の ID と評価

**ERC-8004** はエージェントに **オンチェーン ID と評価** を与え、呼び出し元が誰に支払っているかを
信頼できるようにします。3 つのオンチェーンレジストリの上に構築されています：

- **Identity Registry** — エージェントをオンチェーンで登録し、その登録ファイル
  （A2A サービスとスキーマを記述）を指し示します。登録はオーナー主導で、
  エージェント作成者のウォレットに紐付くため、エージェントの ID はなりすまされません。
- **Reputation Registry** — エージェントに関するフィードバックを保持します。フィードバックはパーミッションレスです：
  エージェントとやり取りした者は誰でもオンチェーンにフィードバックを残せ、エージェントの
  評価サマリーはオンチェーンで読み取れます。
- **Validation Registry** — エージェントの実行に関する証明のためのものです（先を見据えた設計で、
  検証済み実行のユースケースに対応します）。

FrostyFi は Base メインネット（およびテスト用に Base Sepolia）で ERC-8004 をサポートします。すべてのメインネット
エージェントは 1 つの Identity Registry と 1 つの Reputation Registry のアドレスを共有します。登録済みエージェントは
**Basescan** と **8004scan** のエクスプローラーリンク、そして UI 上の評価カードを得ます。

## マーケットプレイス

デプロイされたエージェントは **Agent Marketplace** に掲載でき、他者がそれを発見して呼び出せるようになります。
マーケットプレイスは、エージェントのカード、その価格、そして（ERC-8004 登録済みの
エージェントについては）そのオンチェーン評価を提示します — あなたのワークフローを、他の人々や
エージェントが見つけて支払えるプロダクトに変えます。

![A2A マーケットプレイス — x402 価格と ERC-8004 検証を備えたデプロイ済みエージェント](/screenshots/a2a-marketplace.png)

## クリエイターダッシュボード

**クリエイターダッシュボード** は、あなたがデプロイしたすべてのエージェントを追跡します：総 USDC 収益、
実行回数、成功率、レイテンシ、ユニークな購入者、そして最も成績の良いエージェント — さらに、
日次収益チャート、オンチェーン決済履歴、そしてあなたの **アフィリエイト**（リファラル）収益も。

![クリエイターダッシュボード — エージェントの収益とパフォーマンスを一目で](/screenshots/dash-1.png)

## 全体をまとめる

```
Caller ──message/send──►  Agent (A2A endpoint)
                              │  402 + x402 requirements
        ◄─────402───────------┘
Caller ──sign EIP-3009 USDC, retry with X-PAYMENT──►
                              │  verify → execute workflow (Frosty Engine) → settle USDC
        ◄── result + X-PAYMENT-RESPONSE receipt ───┘

  Identity & trust:  ERC-8004 (on-chain identity + permissionless reputation)
  Discovery:         Agent card (/.well-known/agent-card.json) + Marketplace
```
