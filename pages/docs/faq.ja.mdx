# FAQ

## 一般

**Q: FrostyFi とは何ですか？**
A: ブロックチェーン自動化を備えた AI 駆動のワークフローを構築するための、Web3 ネイティブなプラットフォームです。

**Q: 使うのに暗号資産は必要ですか？**
A: はい、サブスクリプションには Base チェーン上の USDC が必要です。お試し用に無料ティアが利用できます。

**Q: どこでホスティングされていますか？**
A: app.frostylabs.ai（フロントエンド）、Oracle Cloud VPS（バックエンド）

## 技術

**Q: どのモデルがサポートされていますか？**
A: あらゆる主要プロバイダー（OpenAI、Anthropic、Google、xAI、Groq など）が単一のゲートウェイ経由で利用できます — すべてのチャットモデルは OpenRouter 経由でルーティングされます。[モデルと使用量](/docs/models) を参照。

**Q: 自分の API キーを使えますか？**
A: いいえ — LLM アクセスは、ユーザーごとの月間予算（Cursor のような）とともに、OpenRouter を通じて FrostyFi が管理します。プロバイダーキーを持ち込んだり管理したりすることはありません。

**Q: 私のデータは安全ですか？**
A: はい — ユーザー単位の分離があり、ブロックチェーンの署名は ThirdWeb Vault を通るため、秘密鍵があなたのワークフロー設定に触れることはありません。

**Q: セルフホストできますか？**
A: まだできません — FrostyFi は今日のところ SaaS 専用です。セルフホストのオプション（Docker/Coolify）は[ロードマップ](/docs/roadmap)にあります。

## アカウント

**Q: アカウントをどう復旧しますか？ パスワードを忘れました。**
A: パスワードはありません。FrostyFi のアカウントはウォレットベースです — あなたのウォレットが **そのまま** あなたのアカウントです。セッションが失効したりログアウトされたりした場合は、同じウォレットを再接続するだけで、すべてが元のまま戻ってきます。

**Q: ウォレットへのアクセスを失ったらどうなりますか？**
A: あなたのウォレットの秘密鍵 / シードフレーズだけが唯一の復旧手段です — どこか安全な場所にバックアップしてください。鍵が失われた場合、私たちを含め誰もそのアカウントを復旧できません。メールまたはソーシャルログイン（ThirdWeb のアプリ内ウォレット）でサインアップした場合、復旧は代わりにそのメール/ソーシャルアカウントに紐付いた ThirdWeb のフローを通じて行われます。

## 請求

**Q: サブスクリプションはどう機能しますか？**
A: サブスクリプションは、`FrostySubscription` スマートコントラクトを通じて Base 上の USDC で支払われます — あなたのティアは、あなたのウォレットに対してチェーンから直接読み取られます。クレジットカードも NFT もありません。[サブスクリプションと料金](/docs/pricing) を参照。

**Q: 解約できますか？**
A: はい — 単に更新しないだけです。サブスクリプションが失効すると、あなたのティアはオンチェーンで失効します。
