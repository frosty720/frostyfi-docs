# サブスクリプションと料金

FrostyFi には 3 つのティアがあります。サブスクリプションは、`FrostySubscription` スマートコントラクトを通じて
**Base 上の USDC** で支払われます — クレジットカードも、管理すべき NFT もありません。あなたの
ティアは、あなたのウォレットに対してチェーンから直接読み取られます。

## ティア

![アプリ内の料金ページ — Free、Pro、Enterprise の各ティア](/screenshots/pricing.png)

| | **Free** | **Pro** | **Enterprise** |
|---|---|---|---|
| 価格 | $0/月 | **$25/月** | **$99/月** |
| チャットモデル | 無料モデルのみ | **全モデル** | **全モデル** |
| 月間の使用量 | 50 回（無料モデル） | ≈月 400〜4,700 回のプレミアム呼び出し（モデルにより変動） | ≈月 1,500〜18,000 回のプレミアム呼び出し（モデルにより変動） |
| ワークフロー | 5 | 50 | 無制限 |
| バックグラウンド実行（Frosty Engine） | — | ✅ | ✅ |
| ワークフローをエージェントとしてデプロイ（A2A / x402） | — | ✅ | ✅ |

あなたの呼び出し回数はフラットな数値ではありません — **選ぶモデルに応じてスケールします**。より安い
モデルはずっと長く持ち、フロンティアモデルは呼び出しごとに月間許容量をより多く消費します。
月間の使用量と **残り呼び出し回数（≈）** メーターの
仕組みについては、[モデルと使用量](/docs/models)を参照してください。モデルアクセスはバイナリ（二択）です：Pro と Enterprise は両方とも *すべて* の有料モデルを得ます — 
モデルごとのティアゲーティングはありません。

## 決済の仕組み

サブスクリプションは **Base 上の USDC（6 桁の小数）** で決済されます。アプリは 2 つのオンチェーン
購入フローをサポートします：

- **Approve + subscribe（2 トランザクション）** — スマートコントラクトウォレットを含む、
  すべてのウォレットで機能します。
- **`subscribeWithAuthorization`（1 トランザクション、EIP-3009）** — ガスレス風の単一
  署名で、EOA ウォレットで利用できます。

サブスクライブするには：

1. ウォレットを接続する（または、埋め込みウォレットを発行するメール/ソーシャルログインを使う）。
2. 料金ページで **Pro** または **Enterprise** を選ぶ。
3. USDC の支出を承認して確認する。
4. あなたのティアが直ちにオンチェーンで切り替わり、使用量の予算が発行されます。

`FrostySubscription` コントラクトは Base 上にデプロイされています（メインネット `0x80f6…3716`、
チェーン ID 8453）。テスト用の Base Sepolia デプロイ（`0xF23B…31bd`）もあります。このコントラクトは
FrostyFi の以前の NFT/Unlock ベースのサブスクリプションを置き換えました。

## アフィリエイト / リファラルプログラム

FrostyFi は、あなたが連れてきたサブスクリプションに対して **リファラル報酬** を支払い、オンチェーンで決済します：

- あなたのウォレットをリファラーとしたリンク（`?ref=<your-wallet>`）を共有します。リファラルは
  サインインのリダイレクトを生き延びる Cookie に記録されます。
- 誰かがあなたのリンク経由でサブスクライブすると、あなたのウォレットがオンチェーンの
  `referrer` として渡され、コントラクトがあなたの取り分を請求可能な **リファラル残高** に積み立てます。
- いつでも **クリエイターダッシュボード → Affiliate Earnings** カードから収益を請求できます
  （スプリッターの `claimAffiliate()` を呼び出します）。

アフィリエイトプログラムは、**3 つのスティッキーなレベルにわたって 10%** を支払います — 直接の
リファラーに **6%**、その上位 2 レベルに **2.5%** と **1.5%** — オンチェーンに請求可能な
残高として積み立てられます。あなたのアップラインは、被リファラーユーザーの最初の支払い時に一度だけ設定され、その後は固定されます。
**リファラーなし？ その取り分は代わりに POL に資金を供給します。** 自己リファラルは無視されます。

> USDC です。$FROST は主に **有料顧客によって獲得** され、一部はボンドを通じて販売されます。設計については [トークノミクス](/docs/tokenomics)
