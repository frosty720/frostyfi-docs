# 订阅与定价

FrostyFi 有三个套餐。订阅通过 `FrostySubscription` 智能合约以 **Base 上的 USDC** 支付——无需信用卡，也没有需要管理的 NFT；你的套餐直接根据你的钱包从链上读取。

## 套餐

![应用内定价页面——免费版、Pro 版与企业版](/screenshots/pricing.png)

| | **免费版** | **Pro 版** | **企业版** |
|---|---|---|---|
| 价格 | $0/月 | **$25/月** | **$99/月** |
| 聊天模型 | 仅限免费模型 | **全部模型** | **全部模型** |
| 月度用量 | 50 次调用（免费模型） | ≈400–4,700 次高级调用/月（随模型而异） | ≈1,500–18,000 次高级调用/月（随模型而异） |
| 工作流 | 5 个 | 50 个 | 无限 |
| 后台执行（Frosty Engine） | — | ✅ | ✅ |
| 将工作流部署为智能体（A2A / x402） | — | ✅ | ✅ |

你的调用次数并非一个固定数字——它**随你所选的模型而变化**。更便宜的模型能撑得更久；前沿模型每次调用会占用更多月度额度。关于月度用量与 **≈ 剩余调用次数**计量表的运作方式，参见[模型与用量](/docs/models)。模型访问是二元的：Pro 版与企业版都能使用*每一个*付费模型——不存在按模型划分的套餐门槛。

## 支付如何运作

订阅以 **Base 上的 USDC（6 位小数）**结算。应用支持两种链上购买流程：

- **授权 + 订阅（2 笔交易）** —— 适用于所有钱包，包括智能合约钱包。
- **`subscribeWithAuthorization`（1 笔交易，EIP-3009）** —— 一种类无 gas 的单次签名，面向 EOA 钱包提供。

订阅步骤：

1. 连接你的钱包（或使用邮箱/社交登录，它会创建一个嵌入式钱包）。
2. 在定价页面选择 **Pro 版**或**企业版**。
3. 授权 USDC 支出并确认。
4. 你的套餐会立即在链上切换，你的用量预算随即被开通。

`FrostySubscription` 合约已部署在 Base 上（主网 `0x80f6…3716`，链 ID 8453），并有一个 Base Sepolia 部署（`0xF23B…31bd`）供测试。该合约取代了 FrostyFi 早先基于 NFT/Unlock 的订阅。

## 联盟 / 推荐计划

FrostyFi 会为你带来的订阅支付一份**推荐分成**，在链上结算：

- 分享一个以你的钱包为推荐人的链接（`?ref=<你的钱包>`）。推荐信息会被记录在一个 cookie 中，可在登录重定向后依然保留。
- 当有人通过你的链接订阅时，你的钱包会作为链上 `referrer` 被传入，合约会把你的分成累积到一个可领取的**推荐余额**中。
- 你可以随时在**创作者仪表盘 → 联盟收益**卡片中领取你的收益（会调用分账器上的 `claimAffiliate()`）。

联盟计划支付**跨三个粘性层级的 10%**——**6%** 给直接推荐人，**2.5%** 与 **1.5%** 给上面的两个层级——在链上累积为可领取余额。你的上线在被推荐用户首次支付时一次性设定，之后固定不变。**没有推荐人？那份分成会转而为 POL 提供资金。** 自我推荐会被忽略。
