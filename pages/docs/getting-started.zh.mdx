# 快速上手

本指南将带你走过在托管版应用 [app.frostylabs.ai](https://app.frostylabs.ai) 上的头五分钟：登录、发送首次聊天、选择模型，以及从模板创建工作流。

## 1. 登录

FrostyFi 使用 **ThirdWeb Auth**——身份验证基于钱包，会话是存储在 cookie 中的 JWT（有效期 7 天）。你有两种登录方式：

- **连接钱包** —— MetaMask、Coinbase Wallet、Rainbow，或任何 WalletConnect 钱包。系统会要求你签署一条消息（Sign-In With Ethereum）。无需交易，无需 gas。
- **邮箱 / 社交登录** —— 使用邮箱或社交账号（Google 等）登录。ThirdWeb 会在后台为你创建一个嵌入式钱包，因此你无需管理助记词也能获得一个链上地址。

无论哪种方式，你最终都会得到一个钱包地址，它就是你在聊天、工作流、订阅和智能体之间的统一身份。

## 2. 你的首次聊天

登录后，你会进入聊天工作区。输入一条消息并发送——响应会实时流式返回（FrostyFi 底层使用 Vercel AI SDK）。

![FrostyFi 聊天工作区](/screenshots/chat-workspace.png)

在聊天中你可以做的几件事：

- **附加文件**供模型读取。
- **`@提及`一个助手**，引入一位带有量身定制人设与技能集的推理专家（例如分析师或文案）。参见[核心概念](/docs/concepts#assistants)。
- **`@提及`一个工作流**，把你的某个工作流作为工具内联运行，并在对话中取回其输出。

## 3. 选择模型

在聊天编辑器中使用**模型选择器**来选择由哪个 AI 模型回答你。每个托管模型都经由 [OpenRouter](/docs/models) 路由，因此你获得的是一个统一、一致的选择器，而无需在各提供商密钥之间来回切换。

![模型选择器，带文本 / 图像 / 视频标签页及剩余调用次数估算](/screenshots/model-picker.png)

- **免费版**可看到**免费模型**（`:free` 系列——性能强劲、$0 的开源模型）。
- **Pro 版与企业版**可看到这些模型**外加精选的付费旗舰模型**。模型访问是二元的：每个付费套餐都能使用*每一个*付费模型——不存在「此模型仅限企业版」的门槛。

选择器还会显示一个**≈ 剩余调用次数**估算，它会在你切换模型时更新，让你大致了解在所选模型上你的月度预算能买到多少用量。该数字的计算方式参见[模型与用量](/docs/models#the-calls-left-estimate)。

## 4. 从模板创建你的首个工作流

![工作流模板库](/screenshots/templates-gallery.png)

获得一个可用工作流的最快方式是克隆一个**模板**：

1. 从侧边栏打开**模板**。
2. 浏览或搜索模板库（模板按类别分组——加密货币/交易、自动化等等）。
3. 点击**使用模板**。FrostyFi 会把模板克隆到你自己的工作区（节点 ID 会被重新映射，因此它完全归你编辑）。
4. 你会被带入**可视化工作流构建器**，在其中可以重新连接节点、修改提示词并添加步骤。

![可视化工作流构建器](/screenshots/workflow-canvas.png)

每个工作流都以一个**输入（Input）**节点开始，以一个**输出（Output）**节点结束。要了解每个节点的作用，参见[工作流与节点](/docs/workflows)。

## 5. 运行、定时或部署它

- **内联运行：** 在聊天中`@提及`该工作流以运行一次并查看输出。
- **定时或 webhook 触发：** 将其部署到 [Frosty Engine](/docs/workflows#frosty-engine)，使其按 cron 计划或在外部服务调用其 webhook 时在后台运行。（后台执行需要 Pro 或企业版[订阅](/docs/pricing)。）
- **发布为智能体：** 将该工作流变成一个他人可调用的、付费的链上 [A2A 智能体](/docs/agents)。
