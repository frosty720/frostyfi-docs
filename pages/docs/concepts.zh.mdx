# 核心概念

FrostyFi 有几个基础构件，由于它们都与「AI」相关，容易被混淆。本页会精确定义每一个，并且——最重要的是——划清**助手（Assistant）**与**智能体（Agent）**之间的界线。

## 工作流

**工作流（Workflow）**是核心功能：一种在拖放式画布上构建的可视化、基于节点的自动化。工作流是一张由**节点**（步骤）通过**边**（数据流）连接而成的有向图。它始终从一个**输入（Input）**节点开始，到一个**输出（Output）**节点结束；中间你可以连接 LLM 调用、HTTP 请求、条件、代码、区块链操作、循环以及各类集成。

工作流以节点 + 边的形式存储在数据库中。它们有三种运行方式：

- **内联运行** —— 在聊天中通过 `@提及` 并作为工具执行。
- **后台运行** —— 部署到 [Frosty Engine](/docs/workflows#frosty-engine)，按 cron 定时或通过 webhook 运行。
- **作为智能体运行** —— 发布后，外部调用方即可调用它们（见下文智能体）。

完整节点库参见[工作流与节点](/docs/workflows)。

## 助手

**助手（Assistant）**是一位**推理型聊天专家**。可以把它理解为一个已配置的角色人设——一个职责/专长、一段系统提示词、一组技能以及一组工具——你可以在聊天中用 `@` 召唤它。

关键特性：

- **与模型无关。** 助手不绑定某一个模型；它运行在你在模型选择器中所选的任意模型上。
- 在聊天中**可 `@提及`**。当你提及某个助手时，它的人设与技能会被注入到对话中。
- **无法被部署。** 助手存在于聊天运行时之内——它们没有无头的后台运行时，因此*不会*被直接转变为 x402/A2A/ERC-8004 端点。如果你需要把某个助手的行为作为可部署单元，请将其构建进一个工作流（**智能体节点（Agent node）**可让工作流嵌入类助手的推理能力）。

## 智能体

**智能体（Agent）**是一个**已部署的工作流智能体**。它是一个被发布为实时可调用端点、并拥有链上身份的工作流。在 FrostyFi 的模型中，*「工作流智能体」与「A2A 智能体」是同一件事*——同一条记录，被标记为可部署。

一个智能体为你提供：

- 一个 [A2A](/docs/agents#a2a-protocol) 端点和一张可被发现的**智能体卡片**。
- 可选的 [x402](/docs/agents#x402-payments) 按次调用 USDC 支付。
- 可选的 [ERC-8004](/docs/agents#erc-8004-identity--reputation) 链上身份与信誉。
- 在[市场](/docs/agents#marketplace)中的一条挂牌。

### 助手 vs. 智能体——精确的区别

| | **助手** | **智能体** |
|---|---|---|
| 它是什么 | 一个推理型聊天人设 | 一个已部署的工作流 |
| 是否由工作流支撑？ | 否（`workflowId` 为 null） | 是（拥有 `workflowId`） |
| 在哪里运行 | 在聊天运行时内部 | 无头，运行于 Frosty Engine |
| 聊天中可 `@提及`？ | 是 | 否——通过其智能体端点调用它，或运行其工作流 |
| 能否被部署？ | 否 | 是——这*正是*它成为智能体的原因 |
| x402 / A2A / ERC-8004？ | 否 | 是 |

简而言之：**助手用于在聊天中思考；智能体用于运行他人可调用并付费的已部署工作流。** 两种形态都*通过工作流*获得同样的变现路径——你把助手的能力组合进一个工作流，再将该工作流部署为智能体。

## 技能

**技能（Skill）**是**注入到助手中的、仅含指令的文档**。技能既不是代码，也不是工具——它是一段指导内容（最佳实践、一套流程、领域知识），会被添加到助手的系统提示词中。当用户的请求与某个技能匹配时，助手就会遵循该指导。

技能是你在不编写软件的情况下，教会助手*如何*做某件事的方式。你在助手编辑器中为助手附加技能。

## MCP 服务器

**MCP 服务器**（[Model Context Protocol](/docs/mcp)）是**工具**的外部来源。连接一个 MCP 服务器，会为你的聊天与助手提供一组可调用的工具（例如市场数据、支付、网页抓取）。

MCP 是**仅限远程**的——你连接到远程（HTTP/SSE）MCP 服务器。市场提供经过审核的远程服务器（例如 CoinGecko、Alpha Vantage、Stripe、Etherscan、Blockscout）。

## 模板

**模板（Template）**是一个**克隆即用的工作流**。模板库包含预构建的公开工作流；点击**使用模板**会将其复制到你的工作区（并生成全新的节点 ID），以便你运行和自定义。模板是最快的起步方式——参见[快速上手](/docs/getting-started#4-create-your-first-workflow-from-a-template)。
