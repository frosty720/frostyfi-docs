# 模型与用量

FrostyFi 将**所有聊天模型都经由 [OpenRouter](https://openrouter.ai) 路由**——一个位于每个主流提供商之前的单一网关。本页解释模型选择器、月度用量如何随你所选模型而变化，以及**≈ 剩余调用次数**计量表。

## 一个网关，一个选择器

![模型选择器，带文本 / 图像 / 视频标签页及剩余调用次数估算](/screenshots/model-picker.png)

FrostyFi 不采用各自独立的提供商集成和各自的密钥，而是把每个聊天请求都通过 OpenRouter 发送。这意味着：

- **一个精选选择器。** 在一处添加或移除某个模型；无需维护并行的工具/视觉表格来保持同步。
- **一套支出控制。** 每个用户的用量都通过一个带有硬性月度上限的按用户 OpenRouter 密钥进行（详见下文）。
- **应用归属。** 每次推理调用都携带 FrostyFi 的归属标头，因此应用会出现在 OpenRouter 的公开排行榜与分析中。

模型分为两个池：

- **免费模型** —— 始终在线的 `:free` 系列（性能强劲、$0 的开源模型，例如 Gemma、DeepSeek、Qwen、GPT-OSS）。OpenRouter 上新的 `:free` 模型会被自动呈现。
- **付费模型** —— 一组精选的旗舰模型。

**模型访问是二元的——`免费`或`付费`。** 免费版仅能看到免费模型；**Pro 版与企业版都能看到每一个付费模型。** 不存在「此模型仅限企业版」的情况。

## 月度用量随模型而变化

你每个月能做多少事，取决于你的[订阅套餐](/docs/pricing)**以及你所选的模型**——这正是公平之处。对轻量模型的一次调用与对前沿模型的一次调用，是截然不同的算力消耗，因此你的额度是按用量而非固定调用次数来衡量的。更便宜的模型能撑得更久；高端模型每次调用会占用更多额度。

| 套餐 | 月度用量 |
|------|---------------|
| **免费版** | 固定 **50 次/月**，**仅限免费模型**。 |
| **Pro 版** | 慷慨的月度额度——大约 **400–4,700 次高级调用/月**，具体取决于你使用的模型。 |
| **企业版** | 更大的额度——大约 **1,500–18,000 次高级调用/月**，具体取决于你使用的模型。 |

当你用尽月度额度时，FrostyFi 会显示一条友好的「已达上限」提示，并在每月月初重置。免费与快速模型对 Pro 版和企业版仍然可用，且不会消耗高级额度。

## 「剩余调用次数」估算

用量计量表会把你剩余的月度额度换算成一个**针对你当前所选模型**的 **≈ N 次剩余调用**估算——而绝不是一个原始的费用数字：

- 切换到**更便宜**的模型，估算就会**上升**。
- 切换到**更贵**的模型，估算就会**下降**。

无论哪种情况，额度都是同一份——计量表只是让你对所用模型上还剩多少有一个诚实、直观的感受。该估算使用一个具有代表性的每次调用 token 分布，因此它是一个参考，而非承诺。

**免费版**的计量表更简单：它只显示已用调用次数相对于固定的 **50 次/月**额度。

## 成本追踪

FrostyFi 会把 OpenRouter 报告的每次调用的真实成本记录进每个用户的单一用量账本。该账本驱动计量表、执行预算，并且是未来将支持 PERMA 代币用量的同一套会计层。
